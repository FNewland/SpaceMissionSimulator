# AOCS / OBC / system mode transitions — the definitive table

**2026-08c item 13.** Written for the procedure-card author: several shipped
cards command transitions the spacecraft performs by itself (and then "fail"
their verify when the spacecraft has already moved on), and several verify a
mode the spacecraft will already have left. This document is generated by
reading `aocs_basic.py` (`_check_auto_transitions`, `_check_emergency`,
`_check_fine_promotion`, `_check_desat_exit`, `set_mode` handler),
`obdh_basic.py`, `engine.py` (`_update_sc_mode`, phase logic) and
`fdir.yaml` / `monitoring/s19_rules.yaml` as shipped, and is cross-checked by
`tests/test_simulator/test_aocs_mode_management.py` and
`test_field_report_2026_08c.py`.

## 1. AOCS modes (`aocs.mode`, 0x020F)

| Code | Name | Kind |
|---|---|---|
| 0 | OFF | power state |
| 1 | SAFE_BOOT | transient (hardware init) |
| 2 | DETUMBLE | transient (B-dot) |
| 3 | COARSE_SUN | transient safe hold — **never a destination** |
| 4 | NOMINAL | operational (LVLH nadir) |
| 5 | FINE_POINT | operational (imaging) |
| 6 | SLEW | transient |
| 7 | DESAT | transient |
| 8 | ECLIPSE | transient (propagate/coast) |
| 9 | INERTIAL | operational (ECI hold) |

`aocs.commanded_mode` (0x0297) latches the ground's INTENT — set only when an
OPERATIONAL mode (4, 5, 9) or OFF is commanded. Every automatic transition
resolves its return path against it. `aocs.mode_demoted` (0x0298) = 1 whenever
`mode != commanded_mode` while an operational mode is commanded.

### 1.1 Commanded transitions (`AOCS_SET_MODE`, S8.1 func 0)

Any mode 0-9 may be commanded, subject to refusal gates (all S1.8, never
silently clamped):

| Target | Refusal gates | Codes |
|---|---|---|
| DETUMBLE (2) | AOCS EPS line off; magnetometer off/failed; MTQ disabled or all rods dead | 0x0004 / 0x0A20 / 0x0A21 |
| FINE_POINT (5) | `aocs.fine_ready` (0x02C5) bitmask must be 0 | 0x0A22 (mask in reply) |
| others | none beyond power gates | — |

Commanding SLEW/DESAT also happens through `AOCS_SLEW_TO` (func 10) and
`AOCS_DESATURATE` (func 1; refused in OFF/SAFE_BOOT/DETUMBLE, in FINE_POINT,
and while the desat inhibit — operator latch or auto-latch during imaging — is
set).

### 1.2 Automatic transitions — DO NOT command these, and do not verify the mode you left

Minimum dwell before any auto transition: SAFE_BOOT 5 s, DETUMBLE 10 s,
COARSE_SUN 20 s, NOMINAL 10 s, FINE 10 s, DESAT 10 s, ECLIPSE 5 s.

| From → To | Trigger (all automatic) |
|---|---|
| any (except OFF/DETUMBLE/SAFE_BOOT) → DETUMBLE | **EMERGENCY**: body rate above the emergency threshold (config; default 5 deg/s) |
| SAFE_BOOT → DETUMBLE | 30 s hardware init complete |
| DETUMBLE → COARSE_SUN | rates < 0.5 deg/s sustained 30 s |
| COARSE_SUN → commanded mode (fallback NOMINAL) | CSS valid AND att_error < 15° sustained 60 s AND star tracker tracking. **COARSE_SUN is a safe hold, never a destination** — a card that commands COARSE_SUN and then verifies `aocs.mode == 3` minutes later will find mode 4 |
| NOMINAL / FINE → ECLIPSE | eclipse entry (5 s debounce). INERTIAL does **not** yield to eclipse |
| ECLIPSE → commanded mode (COARSE_SUN if ST not tracking) | eclipse exit |
| NOMINAL → FINE_POINT | **automatic re-promotion** when FINE is the commanded mode and 0x02C5 == 0 sustained 30 s. Cards should command FINE once; after any transient (eclipse, desat) the spacecraft re-enters FINE by itself |
| FINE → NOMINAL | ST loses track, or < 3 wheels active (demotion; auto re-promotion applies) |
| SLEW → return mode | slew complete (returns to the mode it left, FINE via NOMINAL) |
| DESAT → return mode | body momentum inside deadband, or envelope ≤ exit target, or wheel speeds down — sustained 10 s; **or** timeout (`desat_ineffective` 0x029C = 1, event 0x020E) |
| any → DESAT | autonomy: S12 monitor on `aocs.h_env_frac` (0x02BA) fires S19 rule ea_id 2001 → S8 func 1 |
| NOMINAL family → COARSE_SUN | FDIR rule `aocs.att_error > 5°` (level 2, `min_phase: 6`) action `safe_mode_aocs` — commands COARSE_SUN, from which the auto-resume above applies |

### 1.3 Estimator note (2026-08c item 11)

In COARSE_SUN, once the vehicle is quiescent (|rate| < 0.25 deg/s) and the
selected star tracker holds ≥ 5 stars, the ST **aids the MEKF**
(`aocs.est_source` 0x02C1 bit 0 sets). Gyro-bias calibration
(`AOCS_GYRO_CALIBRATION`) is therefore startable at COM-003, before COM-004
enables the wheels. Its precondition is now exactly:

* all three gyro units powered (else 0x0A02; AOCS powered else 0x0A01),
* selected ST tracking ≥ 5 stars AND est_source bit 0 set (else 0x0A03),
* |rate estimate − reference| ≤ 0.10 deg/s (else 0x0A04).

DETUMBLE never sets est_source bit 0, so calibration remains refused there.

## 2. OBC / OBDH transitions

| Transition | How | Notes |
|---|---|---|
| bootloader → application | `OBC_BOOT_APP` (S8.1 func 55), ~10 s CRC check | on success `obdh.sw_image` 0x0311 → 1 and `obdh.mode` 0x0300 → 0 (NOMINAL); **mission phase advances 3 → 4 automatically**. Boot-image-corrupt failure stays in bootloader (event 0x0305) |
| application → bootloader | `OBC_REBOOT` (func 52, critical) — or automatic: watchdog timeout (armed in application + mode NOMINAL), memory-error reboot, injected faults | reboot cause in 0x0316 |
| OBC mode NOMINAL/SAFE/EMERGENCY | `OBC_SET_MODE` (func 50): 0 = NOMINAL, 1 = SAFE, 2 = EMERGENCY | **commanded only** — no automatic OBC-mode change except FDIR rule `tcs_obc_overtemp_safe_mode` (S19 ea 3003, acts via func 40/50 path). `obdh.mode` drives the MCS contingency banner (M8) |
| OBC A ↔ B | `OBC_SWITCH_UNIT` (func 53, critical); FDIR can command switchover on excessive reboots | |
| CAN bus A ↔ B | `OBC_SELECT_BUS` (func 54); FDIR ea 5002 on excessive reboots | |

## 3. System-level modes

### `sc_mode` (SAFE/NOMINAL/SCIENCE/EMERGENCY — derived, 0x0001)

Recomputed every tick by the engine, **never commanded directly**:

* EMERGENCY — an FDIR emergency contingency is latched;
* SAFE — an FDIR safe contingency is latched **or** mission phase < 6;
* SCIENCE — commissioned, no contingency, payload IMAGING;
* NOMINAL — otherwise.

It recovers automatically as contingencies clear. There is no TC that sets
sc_mode; cards that "command safe mode" should command the CAUSE they mean
(OBC_SET_MODE 1, or an FDIR action), and cards that verify NOMINAL must first
have declared phase 6.

### Mission phase (`eps.spacecraft_phase`, 0x0129)

* 3 → 4: **automatic** on successful OBC_BOOT_APP.
* 4 → 5 → 6: **commanded only** — `SYS_SET_MISSION_PHASE` (S8.1 func 120,
  critical; args phase + flags, bit 0 FORCE for backwards). Refusals: 0x0C01
  out of range, 0x0C02 phases 0-2 always, 0x0C03 phase ≥ 4 in bootloader,
  0x0C04 backwards without FORCE.
* Phase 6 is what unlocks sc_mode NOMINAL and the propulsion arm interlock.

### EPS mode (`eps.eps_mode`, 0x0137)

`EPS_SET_MODE` (func 83): 0 NOMINAL, 1 SAFE (sheds the two least-essential
loads), 2 EMERGENCY (sheds all). Commanded only (plus FDIR safing actions);
loads are restored by the operator, never automatically. Load-shed stages are
separately commandable via `EPS_EMERGENCY_LOAD_SHED` (func 25, stages 0-3;
stage N sheds the first N of payload / fpa_cooler / ttc_tx; stage 0 clears the
latch without re-powering) and are entered autonomously by the bus-voltage
shedder below 26.5 V. Stage in 0x0134; events 0x0106-0x0108 fire per stage.

### TTC regimes (for completeness)

Beacon MODE (the S-band ladder latch, func 70) is entered by the bootloader
automatically and **left only by command** (`TTC_SET_BEACON_MODE on=0`) —
OBC_BOOT_APP deliberately does not clear it. The rate ladder's SAFE rung
(1 kbps, ex-BEACON) is commanded on SC_SAFE entry automatically (edge-
triggered); tier demotions (antenna/DOWNLINK gates) are automatic on the
ACTIVE tier only and auto-revert — the COMMANDED tier survives. There is no
on-board elevation gate (2026-08c item 5): the 10° HIGH rule is ground policy.
