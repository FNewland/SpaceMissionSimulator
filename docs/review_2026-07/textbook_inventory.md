# SpaceCDF Textbook — Capability / Subsystem / Operational-Function Inventory

**Source:** *SpaceCDF — A Course Textbook*, SCDF-TEXT-001 Issue 1, 2026-05-21, University of Ottawa SEDTI (546 pp.).
**Purpose:** complete inventory of every spacecraft/mission capability, subsystem and operational function the book teaches or assumes, for comparison against the EO-Sat-1 / EOSAT-1 companion simulator.
**Page numbers** are the PDF's printed "Page N of 546" pagination. Book structure: Part 1 "CubeSat Design" (Ch 1.1–4.4, pp. 29–302), Part 2 "CubeSat Operations" (Ch 5–16, pp. 303–508), Appendices A–D (pp. 509–540), Index (p. 541).

**Depth legend:**
- **M** = mentioned/contextual only
- **F** = taught with formulas/derivations
- **W** = worked numerical example(s)
- **X** = SpaceCDF design-tool exercise (Part 1 chapters end with "SpaceCDF Exercise" + Worksheet)
- **S** = simulator-linked operations content (EOSAT-1 console procedures, telemetry, commands in Part 2)
- **V** = first-principles verification in Appendix C (pp. 529–537)

## 4. Internal consistency flags the differences report should know about

The book itself flags (or contains) these design-text ↔ simulator mismatches:

1. **Idle power:** 70 W simulator artefact vs realistic 8–14 W 6U (p. 309, 371).
2. **Battery:** 120 Whr simulator vs realistic 30–40 Whr (p. 309, 371).
3. **Bus voltage:** 4S/27 V simulator vs common 2S/8 V (pp. 325, 459); design chapters teach 2S as the CubeSat standard (p. 147).
4. **FPA cooler:** Peltier, clamped [−20, 0] °C in simulator vs Stirling ≤ −50 °C on real missions (pp. 326, 402, 439).
5. **Downlink rates:** only 1 / 64 kbps modelled (p. 400) — yet Part 1 sizes S-band links at 1–5 Mbps and the MPS exercise uses a "downlink at 1 Mbps" rule of thumb (p. 360). Chapter 5.20 mode table quotes downlink 2–10 Mbps (p. 313).
6. **Star trackers:** §5.7 says "single-head star tracker" (p. 310) but the command catalogue provides ST1/ST2 power + select (funcs 4–6) and Ch 6 handoffs discuss redundant-tracker selection.
7. **AOCS mode integers:** Ch 6.3 quotes a "canonical" 0=IDLE…4=FINE_POINT table and cites `AOCS_SET_MODE` as func 32 (with WHEEL_ENABLE 34/35 etc., p. 324), while Ch 7.7 / Ch 15.5 give the authoritative catalogue: func 0 with modes 0=OFF…8=ECLIPSE. The book's "source-of-truth reconciliation note" (pp. 311, 324) exists precisely for this conflict; pp. 345–346 lists all legacy command names not present in `tc_catalog.yaml`.
8. **S12 monitor count:** 25 (p. 338, sot_index) vs "38 active in nominal config" (Ch 15.2 heading, p. 497).
9. **Passes per day:** §5.7 gives 4 (Iqaluit) + 3 (Troll); Ch 8.2.1 (p. 358) gives ~14/24 h across both stations.
10. **Propulsion:** taught fully in Part 1; in Part 2 EOSAT-1 has orbit-maintenance procedures (NOM-004/005, `PROP_ARM`, CTG-006) and a thruster heater, but no propulsion block in the S8 function tables (0–82) and no propulsion in the §5.7 spacecraft description — the strongest candidate for a "book covers it / simulator doesn't implement it" divergence.
11. **Wheel limits:** simulator wheel max 5000 rpm (Ch 13.7, p. 414) vs S12 red band / S19 desat trigger at 8000 rpm (pp. 323, 498).
12. **FDIR tables:** design/ops text speaks of "FDIR table loaded"; simulator has no table-swapping — only per-rule S19 enable/disable (pp. 323, 377).
13. **Simulator positions:** the MCS exposes six on-console positions; FD, Mission Manager and FDS are off-tool, and "the FDS seat is the operations programme's addition to the simulator's six positions" (pp. 321, 329).
14. **Placeholders:** several Ch 14 contingency cards are "placeholders awaiting simulator content"; `procedure_index.yaml` is the authoritative list (p. 496).
15. **No OBCP / on-board scripting:** the book never mentions on-board control procedures or scripting; autonomy = S11 time-tagged schedules + S19 event-action rules only. If the simulator implements OBCPs (or the professor expects them), that is outside the book's scope.
