RECOVERY & RESPONSE CONTROLS

Only controls backed by a real command are offered here: per-monitor enable/disable is TC(12,3)/TC(12,4), per-rule enable/disable is TC(19,4)/TC(19,5), and the report requests are TC(12,12)/TC(19,8) — all in commands/tc_catalog.yaml. There is no “set FDIR level” or “clear latched flag” telecommand on this spacecraft: the level shown above is derived on the ground, and the SAFE / EMERGENCY latches clear on board when the triggering condition clears. ACK is a ground action only — it silences the console badge and never touches the spacecraft.

An S19 action on this spacecraft is exactly ONE parameter-less S8 function — there is no multi-step autonomous response.
